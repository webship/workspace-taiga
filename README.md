# @webship.co/workspace-taiga

Taiga, the open-source agile project management platform, for the [Webship Workspace](https://github.com/webship/workspace)
dashboard. It brings a builder that makes a real Taiga site in containers (DDEV by default) from Taiga's own images,
with its database, its default accounts and a sample project, the Taiga step pack wired into the workspace's testing
setup, and its user stories as work items of the tracker family
([`@webship.co/workspace-tracker`](https://github.com/webship/workspace-tracker)): read one, analyze it, and let the
workspace's AI CLI work it on a branch, with a person in charge.

The builder, the provider, the tests and CI come with the first release, `1.0.0`.
